FAQ

Common BSJ questions

These are the questions players tend to ask first when they encounter the expanded BSJ systems.

Why can't I record everything my character starts with?

Because baseline restriction can block starting profession and trait bonuses from being recorded as if they were earned later.

Why did a loot journal say it had no claims left?

The server may be using limited-claim loot journals, which dissolve after a set number of successful claims.

Why does a restored journal behave differently from a clean one?

Restored journals preserve their origin state and can either persist or dissolve based on sandbox settings.

Can worn journals have traits now?

Yes. In the current build they can also carry recipes and forget slots if those options are enabled.

What makes cursed journals different from bloody journals?

Cursed journals can punish the first opener before settling into a richer reward state.

Why am I seeing wrapped holiday journals?

Yuletide season is active through the world date, the host's real date, or both.

Can other players use my personal journal?

Only if the server explicitly allows others to open and claim from personal journals.
