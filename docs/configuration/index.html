Sandbox Guide

Configuration categories that matter

The current build exposes a wide sandbox surface. This page groups it the way players and hosts actually think about it: player journals, loot journals, fun journals, advanced rules, and other-mod compatibility.

Player Loot Loot (Fun) Advanced Other Mods

Journals - Player

AreaWhat it controls
Enable Journals / Enable Player JournalsTurns the overall personal-journal experience on or off.
XP Recovery Mode + Diminishing ReturnsControls how clean journals return recorded XP and whether repeated reads taper off.
Writing / Erasing RequirementsPen usage, eraser requirements, and whether diminishing-return progress survives erase-and-rewrite loops.
Trait / Recipe / Stat RecordingControls which personal-journal tabs are active.
Baseline RestrictionPrevents profession freebies from being stored as earned progress.

Journals - Loot

AreaWhat it controls
Journal XP MultiplierGlobal XP tuning for loot journals.
Passive Skill TogglesWhether Strength and Fitness can appear on loot journals.
Worn Journal groupSpawn chance, skill ranges, XP ranges, trait support, recipe support, and forget-slot rolls for container loot.
Bloody Journal groupDrop chance, skill ranges, XP ranges, trait support, recipe support, and forget-slot rolls for zombie loot.
Limited-Claim Loot JournalsWhether loot journals dissolve after a set number of successful claims.

Journals - Loot (Fun)

AreaWhat it controls
Enable Loot Journals (Fun)Master switch for cursed and Yuletide journal systems.
Cursed Journal settingsSpawn chance, disguise behavior, reward ranges, trait/recipe support, and forget-slot odds.
Yuletide season settingsWorld-date and real-date activation rules.
Yuletide replacement settingsChance for worn or bloody results to be replaced during the active season.
Yuletide reward settingsReward ranges plus gift-item weights and counts.

Journals - Advanced

AreaWhat it controls
Crafting and conversionWhether players can craft journals or restore loot-origin journals into personal ones.
Reading speed and light rulesReading-speed scaling and optional light requirements.
Sharing rulesWhether other players can open or claim from personal journals.
Restored journal dissolutionWhether restored personal journals persist or dissolve when fully claimed.
Baseline snapshots and batchingRecovery safety, cache behavior, and all-in-one batch action tuning.

Journals - Other Mods

BSJ also exposes compatibility toggles for systems that can inject progress a server may not want journals to record or replay.

  • Trait Purchase System skill recording controls
  • Adaptive Traits managed-trait recording controls
  • VHS-derived skill recording controls
Important pattern: these toggles usually hide or ignore incompatible progress sources while preserving already-stored journal data for later re-enable.
