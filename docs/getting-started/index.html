How BSJ feels on a fresh run

You do not need to understand every sandbox toggle immediately. If you know where journals come from, how to open them, and how personal journals differ from loot journals, you can start playing confidently.

First steps

  1. Check the sandbox settings if you are hosting or joining a server with custom rules.
  2. Assume journal actions take time. Most rewards are learned through reading or claiming actions, not instant buttons.
  3. Do not assume every journal behaves the same way. Personal journals, loot journals, cursed journals, and Yuletide journals each follow their own rules.
Light can matter. Some servers require enough light to open or use journals, following the same general idea as vanilla reading restrictions.

Where to look for journals

Personal journals

Crafted or restored by players. These are your long-term progression journals.

Worn journals

Found in shelves, desks, cabinets, and other world containers.

Bloody journals

Found on zombie corpses when the loot settings allow them.

Cursed journals

Rare fun-loot zombie drops that come with consequences.

Yuletide journals

Seasonal replacements for eligible worn or bloody journal rolls.

Opening journals and claiming rewards

  • Use the right-click context menu to open the journal UI.
  • Most journals split rewards into tabs such as skills, traits, recipes, and stats.
  • Entries can be claimed one by one, queued, or batched depending on the journal type and server settings.
  • Loot journals may dissolve after a limited number of successful claims if the server enables that rule.
Cursed journals are not safe blind opens. The first player to break a cursed seal can take the hit before the journal becomes a reward source.

Using personal journals

  • Personal journals can record skills, traits, recipes, and stats if those tabs are enabled.
  • Baseline restriction can block starting profession bonuses from being recorded.
  • Restored journals can behave differently from clean persistent journals depending on server settings.
  • Servers can allow or deny other players opening or claiming from your personal journals.
